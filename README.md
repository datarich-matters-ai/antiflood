# antiflood: เช็คระดับน้ำ & ขอความช่วยเหลือ

เว็บแอปมือถือ (PWA) สำหรับช่วงน้ำท่วม ใช้ได้ทุกจังหวัด เปิดจากลิงก์ได้ทันทีโดยไม่ต้องรอ App Store และกด "เพิ่มไปยังหน้าจอหลัก" ให้ใช้งานเหมือนแอปได้

## ฟีเจอร์
- **ใกล้ฉัน**: ใช้ GPS หาสถานีวัดระดับน้ำที่ใกล้ที่สุด แสดงสถานะ (ล้นตลิ่ง / น้ำมาก / ปกติ / น้ำน้อย) พร้อมคำแนะนำว่าควรทำอะไร หรือเลือกดูทั้งจังหวัด
- **แนวโน้มน้ำ**: บอกว่าน้ำกำลังขึ้นหรือลงกี่ ซม. ในช่วง ~6 ชม. ล่าสุด
- **เขื่อน/อ่างเก็บน้ำ**: % ความจุ น้ำไหลเข้า และปริมาณการระบาย ของเขื่อนใกล้ตัว
- **แผนที่**: ทุกสถานีและเขื่อนทั่วประเทศแยกสีตามสถานะ สถานีน้ำมาก/ล้นตลิ่งแสดงป้าย % และ ▲ ถ้าน้ำกำลังขึ้น กรองดูเฉพาะจุดวิกฤตได้
- **เส้นทาง**: พิมพ์ชื่อเขต/อำเภอ/ถนน หรือกด "ใกล้ฉัน" (3 กม.) เห็นคะแนนโอกาสน้ำท่วมพร้อมที่มาของคะแนน ฝนตกหนักตรงไหน (สถานีวัดฝน ThaiWater) แม่น้ำ/คลองใกล้เคียง ปุ่มเปิด Google Maps โหมดจราจร และลิงก์แชร์เฉพาะพื้นที่ (`#r=lat,lng,km,ชื่อ`) ข้อมูลถนนปิด (กรมทางหลวง) และ Traffy Fondue ยังดึงอัตโนมัติไม่ได้ จึงแสดงเป็นลิงก์ไปยังแหล่งทางการ
- **ขอความช่วยเหลือ**: ระบุตำแหน่งด้วย GPS หรือปักหมุดบนแผนที่ (แจ้งแทนคนอื่นได้) แอปหาที่อยู่โดยประมาณให้ แล้วส่งเข้า Google Form ของทีมช่วยเหลือ ถ้าไม่มีสัญญาณจะเก็บไว้แล้วส่งเองเมื่อกลับมาออนไลน์ แชร์ต่อทาง LINE/SMS ได้ด้วย
- เบอร์ฉุกเฉินกดโทรได้ทันที, เช็กลิสต์เตรียมรับน้ำ, ลิงก์แหล่งข้อมูลทางการ
- ใช้งานออฟไลน์ได้ โดยแสดงข้อมูลล่าสุดที่เคยโหลดไว้

ข้อมูลระดับน้ำมาจาก [ThaiWater (สสน.)](https://www.thaiwater.net/water/wl) GitHub Actions ดึงข้อมูลใหม่ทุก ~5 นาที (GitHub อาจเลื่อนรอบบ้างในช่วงที่คิวแน่น)
แอปนี้ไม่ใช่ช่องทางแจ้งเตือนทางการ ให้ติดตามประกาศจาก ปภ. และอำเภอเป็นหลัก

## Deploy (GitHub Pages)
1. Settings → Pages → Source: **GitHub Actions** (ทำครั้งเดียว)
2. Actions → `update-and-deploy` → Run workflow
3. แชร์ลิงก์ https://datarich-matters-ai.github.io/antiflood/ ผู้ใช้เปิดใน Chrome/Safari บนมือถือได้ทันที ไม่ต้องติดตั้ง

การดึงข้อมูลตามรอบเวลาทำงานบน default branch ของ repo

GitHub Pages สำหรับ private repo ต้องใช้แพ็กเกจที่เสียเงิน ถ้า repo เป็น private และไม่อยากเปิดเป็น public ให้ deploy โฟลเดอร์ `public/` ไป Netlify หรือ Cloudflare Pages แทน แล้วรัน `node scripts/fetch-data.mjs` ตามรอบเวลา

## ตั้งค่าศูนย์รับคำขอความช่วยเหลือ (Google Form)
1. สร้าง Google Form ที่มีคำถามแบบ "คำตอบสั้น" 7 ข้อ ชื่อคำถามต้องมีคำเหล่านี้: **ความเร่งด่วน**, **ชื่อ**ผู้ติดต่อ, **เบอร์โทร**, **จำนวนคน**/กลุ่มเปราะบาง, สิ่งที่**ต้องการ**/รายละเอียด, **ตำแหน่ง** (ลิงก์แผนที่), **ที่อยู่**โดยประมาณ
2. ตั้งค่าฟอร์ม: ไม่ต้องลงชื่อเข้าใช้ และไม่จำกัดเฉพาะคนในองค์กร
3. แท็บ "การตอบกลับ" → ลิงก์กับ Google Sheet แล้วแชร์ Sheet ให้เฉพาะทีมช่วยเหลือ (ข้อมูลมีเบอร์โทรและที่อยู่ ห้ามเปิดสาธารณะ)
4. ใส่ลิงก์ "ส่ง" ของฟอร์มใน `sosFormUrl` ของ `public/config.js` ตอน deploy `scripts/sos-form.mjs` จะจับคู่คำถามให้เอง

## ปรับแต่งรายจังหวัด
แก้ `public/config.js`:
- `provinceHotlines`: เบอร์ศูนย์ ปภ. จังหวัด, ศูนย์พักพิง, อาสากู้ภัยในพื้นที่ (ใช้ชื่อจังหวัดตามที่ ThaiWater สะกด)
- `hotlines`, `links`: เบอร์และลิงก์ส่วนกลาง

## รันบนเครื่อง
```sh
node scripts/fetch-data.mjs      # สร้าง public/data/waterlevel.json
cd public && python3 -m http.server 8000
```

## โครงสร้าง
- `public/`: ตัวแอป (HTML/CSS/JS ล้วน ไม่มี build step), Leaflet อยู่ใน `public/vendor/`
- `scripts/fetch-data.mjs`: ดึงระดับน้ำและข้อมูลเขื่อนจาก ThaiWater แล้วย่อเหลือเฉพาะฟิลด์ที่ใช้ แนวโน้มคำนวณจากประวัติ 12 ชม. (`data/history.json`) ที่เก็บต่อจากรอบก่อน ไม่ต้องเรียก API เพิ่ม ถ้า ThaiWater ล่ม จะใช้ข้อมูลรอบล่าสุดต่อไป
- `.github/workflows/deploy.yml`: ดึงข้อมูลตามรอบเวลาและ deploy
